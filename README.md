# Ruf API Platform

Ruf API Platform — desktop-приложение для полного цикла работы с API: импорт спецификаций, управление коллекциями, выполнение запросов, анализ ответов и обслуживание интеграций в одном рабочем пространстве. Проект ориентирован на локальный workflow и хранение данных на стороне пользователя.

Платформа объединяет API-клиент, инструменты окружений, SQL-функции и встроенный терминал, чтобы сократить переключение между разными приложениями во время разработки, тестирования и отладки. Архитектура построена как модульная и расширяемая, с поддержкой кастомных вкладок и инструментов.

Приложение подходит для backend/frontend-разработчиков, QA и инженеров, которым важно быстро собирать, запускать и повторять сценарии API + SQL без облачной зависимости.

## Фичи проекта

### Импорт и синхронизация API
- Импорт коллекций из OpenAPI/Swagger (JSON/YAML), WSDL (XML), Postman, Insomnia v5 и `.rufcollection`.
- Импорт из файла, текста и URL.
- Импорт через drag-and-drop файлов в рабочую область.
- Вставка из буфера обмена при импорте спецификаций.
- Поддержка локальных `$ref` в OpenAPI (`#/components/...`) и нормализация в OpenAPI v3.
- Автоопределение `sourceUrl/sourceType` для импортированных коллекций.
- Обновление коллекции из исходного URL с сохранением структуры и ID.
- Reload коллекции из файла с предпросмотром diff перед применением.

### Workspace и дерево коллекций
- Workspace-папки для группировки коллекций.
- Дерево коллекций и папок с поиском.
- Сортировка дерева (`none/asc/desc`).
- Глобальное разворачивание/сворачивание дерева.
- Drag-and-drop для коллекций, папок и запросов, включая перенос между коллекциями.
- Создание, переименование, дублирование и удаление коллекций/папок/запросов.
- Быстрый запуск коллекции или папки прямо из дерева.
- Экспорт коллекции в `.rufcollection` (Postman-compatible JSON + RUF metadata).

### Редактор запросов
- Полный HTTP-редактор: метод, URL/URL template, path/query/header параметры, body.
- Поддержка методов `GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS` и кастомных методов.
- Переменные окружения в URL, headers и body (`{{var}}`) с автодополнением.
- Отдельные вкладки для Params, Headers, Data, Authorization, SQL.
- Authorization tab: `None`, `Basic`, `Bearer`.
- Включение/выключение отдельных query/header/file строк.
- История значений для path/query/header с быстрым выбором и очисткой.
- Поддержка enum-параметров из спецификации.
- Body formats: `Auto`, `JSON`, `XML`, `YAML`, `Text`.
- Beautify body для JSON/XML/YAML/Text.
- JSON Code Editor на CodeMirror с подсветкой и variable autocomplete.
- Поддержка `multipart/form-data` и `application/octet-stream` с загрузкой файлов.
- Множественные файлы для multipart.
- Генерация `curl`-команды из текущего состояния запроса.
- Отмена запроса во время выполнения (`Cancel`).

### Выполнение запросов и раннеры
- Отправка запросов с таймаутом и телеметрией (status, time, bytes).
- Подстановка переменных и параметров перед отправкой.
- Data-driven запуск запроса по JSON/CSV датасету.
- Data Input Editor для массовых данных.
- Data Run Report с результатами по каждой строке.
- Collection Runner: запуск всей коллекции или выбранной папки.
- Выбор подмножества запросов перед запуском.
- Итерации запуска (включая batch-прогоны).
- Остановка массового прогона (`Stop`).
- История прогонов коллекций и повторный запуск последнего плана.

### Просмотр ответа и история
- Response tabs: `Body`, `Headers`, `History`.
- Отображение JSON, XML и текстовых ответов.
- Pretty-print XML.
- Подсветка синтаксиса для JSON/XML.
- Поиск по JSON-ответу (JsonPath/фильтры) с количеством совпадений.
- История поисковых запросов по response.
- Копирование body/headers и поисковых выражений.
- Генерация JSON Schema из ответа.
- Сохранение схемы в файл.
- Обработка бинарных ответов с загрузкой файла.
- История запросов по каждому request с сохранением draft-снимка.

### Окружения и SQL-интеграция
- Environment на коллекцию: base URL key, variables, headers.
- Поддержка db-настроек в окружении (PostgreSQL/MySQL).
- Проверка DB-соединения (connection test).
- SQL Pre/Post Script на запрос с включением/выключением каждого скрипта.
- Выбор SQL-соединения для request-level скриптов.
- SQL Terminal drawer с запуском SQL из UI.
- Подключение к SQL Terminal из collection environments и глобальных SQL connections.
- Поддержка PostgreSQL и MySQL в SQL Terminal.
- Result grid + вывод сообщений/ошибок.
- Пагинация результатов (`load more/load all`) для больших выборок.
- Работа со схемами и таблицами, автоподсказки table/column.
- Выполнение текущего SQL statement по позиции курсора.

### Встроенный терминал
- Embedded terminal drawer с вкладками.
- Поддержка shell на Windows: PowerShell и Git Bash (если установлен).
- Поддержка shell на macOS: zsh и Git Bash (если найден).
- История команд, `cd`, `clear/cls`.
- Разрешение и смена рабочей директории.
- Ресайз панели терминала.

### Настройки, безопасность и обновления
- Settings tabs: General, Certificates, Update, SQL.
- Общий таймаут запроса (`request timeout`) в секундах.
- Очистка application cache с отображением размера.
- Переключение проверки TLS-сертификатов.
- Добавление кастомных CA-сертификатов (PEM).
- Инспекция сертификатов: SHA-256, subject/issuer, validity.
- Применение кастомных CA для HTTP и DB соединений.
- In-app updater через GitHub Releases.
- Проверка обновлений, загрузка, отложенная установка и restart для применения.
- Toast-уведомления о доступных обновлениях.

### Хранение данных и desktop-поведение
- Локальное хранение состояния приложения в `localStorage`.
- Persistent localStorage bridge в файловое хранилище через Tauri (`storage_load/storage_save`).
- Автовосстановление состояния UI: активный запрос, open state дерева, размеры панелей и т.д.
- Сохранение request drafts, request history, value history, response search history.
- Кастомный titlebar desktop-окна и нативные window controls.
- Desktop-first реализация на Tauri 2 для Windows и macOS.
